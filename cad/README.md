# 模組 CAD（CadQuery）

單一「模組化對接多旋翼」模組：長方體碳管框架 + ABS 角塊 + 磁鐵對接面 + Crazyflie 2.1。
這份 CAD 算出來的質量、慣量和模組間距，是要取代 `quadsim/params.py` 的假設值（`MODULE_PITCH = 0.10` 等）。是否改用由使用者另外決定，這裡沒有動 `params.py`。

## 重跑

```bash
.venv/bin/python cad/module.py                   # 重新產出 cad/out/ 全部檔案
.venv/bin/python -m pytest -q tests/test_cad.py  # 驗收
```

所有參數都在 `cad/module.py` 檔頭。改 `W`、`H`、`TUBE_OD` 等會整個重新長出來。

## 輸出（`cad/out/`）

| 檔案 | 內容 |
|---|---|
| `module.step` | 彩色 assembly（FreeCAD 可開），每個零件有名字 |
| `module.stl` | 整個模組的外觀網格，單位 mm（MuJoCo 要加 `scale="0.001 0.001 0.001"`） |
| `module_top.svg`、`module_side.svg`、`module_iso.svg` | 俯視、側視、等角 |
| `line3.step` | 3 個模組沿 x 方向對接，中心距 = W，用來目視檢查 |
| `module_props.json` | 預設（ModQuad 方片磁鐵）：質量、質心、慣量、pitch、分項、磁鐵位置、`joint_limits`、每個數字的來源 |
| `module_props_d42.json` | 同上，磁鐵換成 D42-N52（只輸出 JSON） |

`module_props.json` 用 SI 單位，座標原點是框架幾何中心。

## 設計選擇與理由

- **框架**：12 根碳管沿長方體的邊，8 個 ABS 角塊。管子中心線離外表面 4 mm（角塊邊長的一半）。
- **角塊**是 8 mm 立方體，內部挖空（殼厚 1.2 mm），管子從內側三個面的孔插入 2.5 mm。挖空是為了讓質量接近 ModQuad 的 7 g；實心立方體會讓框架多約 1.3 g（約 7.9 g）。
- **磁鐵**：每個側面 2 顆，在側面中線上、上下各一。磁鐵裝在 ABS「磁鐵座」裡，磁鐵座套在上、下邊管子的中點，所以磁鐵中心距 `d = H - CORNER = 40 mm` 由管子位置決定，不是自由參數。磁鐵外表面和框架外表面齊平，所以相鄰模組中心距剛好是 `W`。
  - 選中線而不是角塊的理由：兩顆磁鐵的合力作用在面中心，左右對稱，法向吸力不會產生額外偏心力矩；也不需要額外豎桿。
  - 代價：面內繞法線的扭轉抗力只靠 2 顆磁鐵的剪力；角塊上放磁鐵的話力臂會更大。接頭受力分析時要記得這點。
- **極性**（只記錄，沒有建模）：+x、+y 面上方磁鐵朝外 N、下方朝外 S；-x、-y 面相反。A 的 +x 面貼 B 的 -x 面時，同高度的一對朝外極性相反，所以相吸。代價是模組不能轉 180 度（所有模組 yaw 要一致），這和編隊飛行時 yaw 對齊的情況相同。
- **Crazyflie**：PCB、4 支臂、4 顆馬達（軸距 a = 28 mm）、電池，加 4 個 r = 23 mm 的螺旋槳薄圓盤。只當外觀和干涉檢查，質量和慣量不從幾何算。
- **質量性質**：框架和磁鐵用 CadQuery 實體的體積乘密度，OCC 算各零件對質心的慣性矩陣，再用平行軸定理搬到模組原點。Crazyflie 用 lumped 值（29 g，慣量 = cf2x 慣量 × 29/27，質心在原點）。兩者相加後再搬到總質心。

## 假設（沒有出處的數字）

| 項目 | 值 | 說明 |
|---|---|---|
| 碳管外徑／內徑 | 1.6 / 0.8 mm | ModQuad 沒給管徑；RAL 2019 提到桿徑約 1.37 mm（抽字，未對原圖）。選常見規格 |
| 角塊邊長、殼厚、插入深度 | 8 / 1.2 / 2.5 mm | 為了讓質量接近 7 g 且管子與磁鐵座不互相干涉 |
| 磁鐵座尺寸 | 5 mm 深，7.6 mm 見方 | 磁鐵直徑 6.35 + 兩側各 0.6 mm 壁 |
| Crazyflie 質心 | 框架中心 | 實際會偏低，影響小 |
| Crazyflie 慣量 | cf2x × 29/27 | 假設質量分佈形狀不變 |
| Crazyflie 在框架內的高度 | PCB 在 z = 0 | 螺旋槳盤在 z = +7 mm |
| Crazyflie 與框架的固定件 | 沒有建模 | 實機需要支架，質量未計入，會讓模組略重 |

## 和 ModQuad 的對照

| 項目 | ModQuad（ICRA 2018 / RAL 2019） | 這份 CAD |
|---|---|---|
| 框架外形 | 116 x 116 x 48 mm | 116 x 116 x 48 mm |
| 框架材料 | 碳纖維桿 + 8 個 ABS 接頭 | 12 根碳管 + 8 個 ABS 角塊 |
| 框架質量 | 7 g（ICRA）、6.7 g（RAL） | 6.6 g（管 2.4 + 角塊 2.8 + 磁鐵座 1.5，不含磁鐵） |
| 磁鐵 | 方片 6.35 x 6.35 x 0.79 mm，每個接頭 2 顆 | D42-N52 圓片 φ6.35 x 3.17 mm，每面 2 顆，共 8 顆 |
| 單顆磁鐵質量 | 約 0.24 g（推算） | 0.753 g（K&J 標示 0.75 g） |
| 飛行器 | Crazyflie 2.0，27 g | Crazyflie 2.1，29 g |
| 整個模組質量 | 36.7 g（RAL）、40 g（ICRA） | 41.6 g |

整個模組比 ModQuad 重，主因是 D42 磁鐵比 ModQuad 的薄片重 3 倍（8 顆共 6.0 g），加上 Crazyflie 2.1 比 2.0 重 2 g。如果對接力不需要這麼大，換成更薄的磁鐵可以省約 4 g。

## 磁鐵選項（`MAGNETS`，預設 `modquad_plate`）

| 選項 | 磁鐵 | 8 顆磁鐵質量 | 模組質量 | 推重比（Tmax=0.149 N） | 拉力／剪力／剝離力矩上限 |
|---|---|---|---|---|---|
| `modquad_plate`（預設） | 方片 6.35x6.35x0.79 mm | 1.9 g | 38.1 g | 1.60 | 9.81 N / 2.94 N / 0.196 N·m |
| `d42` | D42-N52 φ6.35x3.17 mm | 6.0 g | 41.6 g | 1.46 | 12.65 N / 3.80 N / 0.253 N·m |

- 改預設的依據：`results/p0/joint_loads.md` 算出接頭最大負載約 2·mg（不到 1 N），D42 的強度遠超過需要，卻讓推重比降低；方片是 ModQuad 實機用的規格（`docs/joint_design_notes.md` 1.1）。
- 磁鐵座的邊長跟著磁鐵寬度走（寬 + 2 x 0.6 mm 壁），兩種磁鐵都是 7.55 mm；凹槽深度 = 磁鐵厚度。
- `joint_limits` 全部是推論，沒有實測：
  - 方片：ModQuad「面對面 4 顆等效 1 kg」，我們面對面 2 + 2 = 4 顆，所以拉力 1 kgf = 9.81 N。若論文的「4 顆」指每側 4 顆，上限會是 2 倍；這裡取保守解讀。
  - D42：K&J 吸鋼板 1.29 kgf，磁對磁取 50%，2 顆 = 12.65 N（`docs` 第 6 節）。
  - 剪力 = 拉力 x 0.3（ModQuad RAL 2019，保守下限 0.15）。
  - 剝離力矩 = 拉力 x d/2（d = 40 mm 的磁鐵間距），粗估。
