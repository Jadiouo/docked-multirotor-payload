## 解讀

1. 8 個構型的 A 秩都是 4，hover 時每顆推力 0.444 Tmax，全部可控，沒有要剔除的。
2. 不知道位置（symmetric）損失的是力臂：square4 的 roll/pitch 下界 52%，grid6 pitch 下界 34%，line4 pitch 下界 26%，同時需求（roll=pitch）最差下界 25%（line4）。**注意 symmetric 只是 L0 的悲觀下界**：模組可以從自己的 IMU 取得額外資訊（見 identifiability.md），真實 L0 表現可能比這個好。
3. 加入 J 非對角項後，L3 的 symmetric 權限從 100 降到 71 rad/s²（比值 0.42），因為要額外抵消 roll/pitch 耦合；對角近似會高估。
4. yaw 比值恆為 1（見下方證明），但 yaw 權限本身隨 N 下降（single 307 → line4 19 rad/s²），這是 oracle 也逃不掉的物理上限。
5. 所有推力相同的 hover 淨力矩恆為 0（含 L3、T4），所以 symmetric 制度可以 hover 不翻。

## yaw 比值恆為 1 的證明

引理：單模組固定總推力 F 時，f(F) 的最大解是把推力集中在同向的對角兩顆馬達（轉向相同的 m0、m2，各 F/2，F ≤ 2Tmax；超過時另兩顆補餘量），此時 τx = a(T2−T0) = 0、τy = −a(T0−T2) = 0，所以模組內自動滿足 τx = τy = 0。

yaw 力矩 τz = km·Σ s_k T_k 只取決於各轉子推力與轉向，和轉子位置無關。對單一模組，在該模組總推力 F 下可達的最大 yaw 是 F 的凹函數 f(F)（LP 的右端項參數化，分段線性）。
整架的 τz 上限 ≤ Σ_m f(F_m)，而 Σ F_m = Mg；由 Jensen 不等式，Σ f(F_m) ≤ N·f(Mg/N)，在總推力平均分配時取等號。
symmetric 解正好是每個模組 F = Mg/N，且各模組同樣輸出 τx = τy = 0 的最佳 yaw，因此它達到這個上界；τx = τy = 0 的約束只會讓 full 的上限更低，不會更高。故 τz,sym = τz,full，而 α_z = τz/Jzz 共用同一個 Jzz（平面構型 Jxz = Jyz = 0），比值 = 1。
數值核對（8 個構型）：無 τx、τy 限制的 τz 上界，full 與 sym 的最大差 = 3.5e-18；表中 yaw 比值的最大偏離 1 = 2.2e-16。無反例。
