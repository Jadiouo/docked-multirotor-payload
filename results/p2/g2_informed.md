# G2-informed：不知道 payload 的代價（2026-10-30）

由 `scripts/g2_informed.py` 產生（原始資料 `g2_informed_raw.json`；古典法讀自 `g2_raw.json`，未更動）。每格 100 個 episode，與 g2 成對（同 seed、同初始條件、同 T2 目標序列）。

**informed** = B1-QP-informed：B1-QP 的分配，但 M、J、轉子相對真實 CoM 的位置（A）都用含 payload 的真實模型（外迴路 α 限幅仍用標稱值，和所有方法相同）；對接偏差與推力係數誤差（all15 才有）仍未知，所以 all15 的 informed 不是完全 oracle。**最強古典法** = 該格 g2_raw 中平均分數最高的古典法（B1、B1-QP、B1-QP+adapt、B2-QP+adapt k=2、B3 INDI、B3+adapt、B4；不含 B5），逐格挑最大值，對古典法有利（選擇偏差）。

**不知道的代價 pp** = 100(1 − 最強古典法分數 / informed 分數)，正 = 不知道比較差；括號為成對 bootstrap 95% CI（episode 重抽 1000 次）。格式「分數 / 成功率」。
